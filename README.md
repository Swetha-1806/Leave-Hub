## 📌 About the Project

**LeaveHub** is a full-stack web application designed to simplify employee onboarding and leave management.

It provides a centralized platform where employees can manage their profiles, apply for leave, and track leave requests, while managers can review and approve leave applications. Administrators can manage employees and monitor overall activities through a dashboard.

## ✨ Key Features

- 👨‍💼 Employee Onboarding and Management
- 🔐 Secure Login and Authentication
- 👥 Role-Based Access Control
- 📝 Employee Leave Application
- ✅ Leave Approval and Rejection
- 📊 Interactive Dashboard and Analytics
- 📅 Leave Status Tracking
- 📧 Email Notifications
- 🚨 Emergency Leave Alerts

## ⚙️ Installation and Setup

### Backend Setup

1. Clone the repository.
2. Open the backend project in Eclipse.
3. Configure MySQL database settings.
4. Update database credentials in `application.properties`.
5. Run the Spring Boot application.

### Frontend Setup

1. Navigate to the frontend folder.
2. Install dependencies:

   `npm install`

3. Start the development server:

   `npm run dev`

4. Open the localhost URL in your browser.
